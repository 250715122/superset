# Superset 看板授权操作指南

> 日常给用户开通/收回某个看板权限的操作手册。原理、脚本细节、踩坑见
> 《Superset变更与生产同步操作手册.md》第六节"授权模型重构"专题。
>
> 模型一句话：**能力和数据都装在角色里、角色装在组里,授权 = 往组里加人。**
> 两环境（开发 192.168.41.122 `/opt/superset`、生产 10.100.19.1 `/mnt/data/superset`）操作完全相同。

---

## 一、只读授权：让某用户能看某个看板

### 常规情况（看板已上线、观众组已存在）——纯页面，1 步

1. 登录 Superset（Admin）→ `Security ▸ List Groups` → 找到该看板的观众组
   （命名如「卡车电池观众」，组里已配好 `只读基线` + `看板·<看板名>`）→
   编辑组，把用户加进 Users 列表，保存。

用户刷新页面即可看到看板。**不要**直接给用户勾角色、更不要在 UI 里给角色加权限。

### 特例

| 情况 | 处理 |
|---|---|
| 看板是新上线的（还没有`看板·X`角色） | 服务器上跑一次 `authz_model.py migrate`（幂等，只会为新看板补角色并挂 RBAC），再回到常规步骤 |
| 受众是全新一批人（现有组都不合适） | `Security ▸ List Groups` 新建组，Roles 勾 `只读基线` + `看板·<看板名>`，再往组里加人 |
| 用户是新注册的 SSO 用户 | 什么都不用做，默认角色就是`只读基线`（零看板、零数据），入组即可见 |
| 看板未发布（Draft） | 先发布（Edit properties → published），否则观众在列表里看不到 |

### 收回

把用户从观众组里移出即可，立即生效。

## 二、读写授权：让某用户能编辑某看板的全部图表

### 常规情况（该看板的编辑组已存在）——纯页面，1 步

1. `Security ▸ List Groups` → 找到「<看板名>编辑」组（组里已配好 Gamma +
   `编辑·<看板名>`）→ 把用户加进 Users 列表，保存。

用户即刻能打开该看板每张图的编辑页（Explore）并保存修改，也能改看板布局。
能编辑的范围**只限这一个看板**——其他看板的图表对他仍是 404。

### 该看板还没有编辑组（每看板一次性初始化）

在服务器上跑一次：

```bash
# 开发
cd /opt/superset && ./venv/bin/python /tmp/editor_group_setup.py <看板id>
# 生产（脚本已在 /mnt/data/superset/）
cd /mnt/data/superset && ./venv/bin/python editor_group_setup.py <看板id>
```

脚本自动完成：建 `编辑·<看板名>` 角色（含该看板全部数据集的授权）→ 挂进看板
RBAC → 建「<看板名>编辑」组。之后回到常规步骤加人。

> 前提（已就绪，无需重复做）：两环境的 `superset_config.py` 已打
> `patch_editor_ownership.py` 补丁——持有挂在看板 RBAC 上的`编辑·X`角色即视同
> 该看板及其图表的 Owner。若某环境重装/回滚过配置，先重跑该补丁并重启。

### 收回

把用户从「XX编辑」组移出即可。若这人还需要只读，把他加回观众组。

### 安全提醒

编辑组成员可以在 Explore 里对该看板的数据集**自由写查询**（不限于现有图表），
只加信得过的人。

## 三、速查表

| 目标 | 操作 |
|---|---|
| 给人开只读 | 加入「XX观众」组 |
| 给人开编辑 | 加入「XX编辑」组 |
| 收回权限 | 从对应组移出 |
| 新看板首次开只读 | `authz_model.py migrate` → 把`看板·X`挂给组 → 加人 |
| 看板首次开编辑 | `editor_group_setup.py <看板id>` → 加人 |
| 改动授权后想验证 | `authz_probe.py`（只读全链路）/ `_editor_probe.py <看板id> <观众>`（编辑） |

## 四、常见问题

- **加进观众组了还是看不到看板**：看板是否已发布？组里是否同时有`只读基线`和
  `看板·X`两个角色？让用户强刷（Ctrl+F5）。
- **能看到图表但点编辑报 404**：说明只有观众身份。编辑必须走「XX编辑」组，
  光加 Owner 或 Gamma 都不行（6.0.1 图表 API 只认数据集授权）。
- **编辑组成员保存报"没有权限修改"**：确认该环境配置里有 `EDITOR_ROLE_PREFIX`
  （补丁在），且`编辑·X`角色确实挂在这块看板的 RBAC 列表里。
- **不要做的事**：不要在 UI 给角色勾权限；不要给观众发任何 datasource/schema/
  database 授权；不要手工建"数据角色"。
